# Markdown Release Notes In Update Dialog

## Status

Active

## Scope

- Affected paths: `lib/utils/update.dart`, `pubspec.yaml`, and `pubspec.lock`.
- Upstream relationship: fork-only.

## Intent

Show formatted release notes in the in-app update dialog, including the linked
commit list generated by the fork release workflow.

## Implementation

- Convert the GitHub Release `body` from Markdown to HTML with the `markdown`
  package and render it with the existing `flutter_html` dependency.
- Preserve Markdown list structure and open rendered links through
  `PageUtils.launchURL`.

## Validation

- `./tool/docker_flutter.sh flutter pub get` resolved `markdown 7.3.1` in
  Docker.
- `./tool/docker_flutter.sh flutter analyze lib/utils/update.dart` completed
  with no issues in Docker.
